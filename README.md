# Тридцать первый — серия 1

Вертикальный анимационный проект Remotion, 1080×1920, 30 fps.

## Превью

1. Остановите старые `npx serve` через Ctrl+C.
2. Установите зависимости: `npm install`.
3. Запустите `npm run preview`.
4. Откройте http://localhost:5051/preview/.

В превью есть управление кадром, проверка сценария, переключение стиля-листа и синтезированные звуки. Если звук не слышен, нажмите «Звук: вкл» и затем ▶. Кнопка «Скачать WAV» сохраняет звуковую дорожку. При ошибке загрузки красная плашка покажет сообщение.

## Remotion и WAV

- `npm run sfx` — создаёт `public/sfx/ep1-sfx.wav`.
- `npm run studio` — генерирует звуки и открывает Remotion Studio.
- `npm run render` — генерирует звуки и рендерит `out/lift-ep1.mp4`.
- `npm run still` — сохраняет кадр в `out/frame.png`.
- `npm run sheet:a` / `npm run sheet:b` — сохраняют кадры стайл-листа в `out/`.

Для `npm run sfx` нужен Node.js 22 или новее. Предупреждение `MODULE_TYPELESS_PACKAGE_JSON` безвредно. Если Node старее, скачайте WAV кнопкой в превью и сохраните как `public/sfx/ep1-sfx.wav`.

Зависимости проекта перечислены в `package.json`. Исходные материалы частей 1–3 сохранены в `source-original.txt`.


## Часть 6 — единый файл озвучки и тайминг сцен

Положите mp3 ElevenLabs как `public/vo/ep1/voice.mp3`. Запустите `npm run sfx`: скрипт ищет паузы, создаёт `public/vo/ep1/timing.json` и пересобирает звуковые эффекты под новую длину сцен. Если фразы определились неверно, откройте `timing.json` и скорректируйте `start` / `end`. В браузерном превью доступны кнопки «Фразы» и «timing.json». После этого `npm run render` собирает `out/lift-ep1.mp4`.

В верхней части кадра оставлены основная жёлтая плашка и зелёный заголовок шага. Для звука требуется файл `voice.mp3`; без него серия работает без озвучки.
